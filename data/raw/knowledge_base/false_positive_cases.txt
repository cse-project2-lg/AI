오탐(False Positive) 케이스 정리

1. 오탐의 정의

오탐(False Positive)이란 실제 낙상이 아닌 상황을 낙상으로 잘못 판단하는 경우를 의미한다.
오탐이 많으면 보호자에게 불필요한 알림이 자주 전송되어 시스템 신뢰도가 낮아진다.
오탐을 줄이기 위해 다음 케이스를 참고하여 판단한다.

2. 주요 오탐 케이스

케이스 1: 빠르게 앉는 동작
- 상황: 사용자가 의자나 소파에 빠르게 앉는 경우
- 센서 패턴:
  - ToF: 빠르게 감소하지만 400mm 이상 유지 (바닥 낙상 기준인 300mm 이하에 해당하지 않음)
  - PIR: 움직임 감지
  - CSI: 변화량 높음
- 낙상과의 차이점: ToF가 400mm 이상으로 유지되며, 앉은 후 PIR에서 소규모 움직임이 지속 감지된다. 사용자 음성 응답이 가능하다.
- 판단 기준: ToF 400mm 이상이고 앉은 후 5초 이내 PIR 재감지 또는 사용자 응답 시 NORMAL로 처리.

케이스 2: 침대나 바닥에 눕는 동작
- 상황: 사용자가 수면을 위해 침대나 바닥에 눕는 경우
- 센서 패턴:
  - ToF: 점진적 감소 후 낮은 위치 유지
  - PIR: 초기 움직임 감지 후 정적 상태
  - CSI: 중간 수준 변화량
- 낙상과의 차이점: ToF 거리 변화가 완만하고(1초 이상), 눕기 전 의도적인 이동 패턴이 선행된다. 낙상처럼 0.5초 이내의 급격한 변화가 없다.
- 판단 기준: ToF 변화 속도가 완만하고 이후 정적 상태 유지 시 수면 상태로 판단하여 NORMAL 처리. 단, 장시간 무동작(30분 이상) 시 ABNORMAL_DETECTED로 전이하여 TTS 확인 수행.

케이스 3: 물건 낙하
- 상황: 무거운 물건이 바닥에 떨어지는 경우
- 센서 패턴:
  - ToF: 변화 없거나 미미함
  - PIR: False (사람 움직임 없음)
  - CSI: 순간적인 변화 후 즉시 안정화
- 낙상과의 차이점: PIR이 False이므로 인체 열이 감지되지 않는다. PIR False 상태에서는 CSI 변동과 ToF 변화가 있어도 무생물 낙하로 판단한다.
- 판단 기준: PIR False 상태에서 발생한 이벤트는 NORMAL로 처리.

케이스 4: 반려동물 움직임
- 상황: 반려동물이 빠르게 이동하거나 점프하는 경우
- 센서 패턴:
  - ToF: 미미한 변화 또는 없음
  - PIR: 약한 반응 또는 없음 (체온이 낮아 PIR 반응이 약함)
  - CSI: 소규모 변화
- 낙상과의 차이점: PIR 반응이 약하거나 없고, ToF 거리 변화가 없거나 미미하다. CSI 변화 패턴이 사람 움직임과 다르다.
- 판단 기준: PIR 반응이 약하고 ToF 변화 없을 경우 NORMAL로 처리.

케이스 5: 가구 이동 또는 청소
- 상황: 청소기 사용, 가구 이동 등 큰 움직임이 발생하는 경우
- 센서 패턴:
  - ToF: 변화 없거나 불규칙
  - PIR: 지속적인 움직임 감지
  - CSI: 높은 변화량 지속
- 낙상과의 차이점: ToF 거리가 300mm 이하로 급감하지 않는다. PIR이 지속적으로 감지되어 무동작 상태로 전환되지 않는다.
- 판단 기준: ToF 급감(300mm 이하) 없이 PIR이 지속 감지되는 경우 NORMAL로 처리.

케이스 6: WiFi 환경 변화로 인한 CSI 드리프트
- 상황: 주변 WiFi 기기 변화, 전자기기 간섭 등으로 CSI 신호가 변화하는 경우
- 센서 패턴:
  - ToF: 변화 없음
  - PIR: False
  - CSI: 지속적이고 일정한 변화 (드리프트 패턴)
- 낙상과의 차이점: PIR 및 ToF 변화 없음. CSI 변화가 급격하지 않고 점진적으로 지속된다.
- 판단 기준: PIR False 및 ToF 변화 없이 CSI만 지속 변화 시 환경 드리프트로 NORMAL 처리.

케이스 7: 센서 오작동 또는 노이즈
- 상황: 센서 이상으로 비정상적인 값이 순간적으로 발생하는 경우
- 센서 패턴:
  - ToF: 유효 범위를 벗어난 값 또는 순간적 이상치
  - PIR: 간헐적 오작동 신호
  - CSI: 비정상적 spike
- 낙상과의 차이점: 이상 값이 순간적이고 반복되지 않는다. 다른 센서와 패턴이 불일치한다.
- 판단 기준: 단일 센서에서 순간적 이상치 발생 시 노이즈로 NORMAL 처리. 복수 센서 동시 이상 시 ABNORMAL_DETECTED로 전이.

3. 오탐 처리 원칙

오탐을 줄이기 위해 다음 원칙을 따른다.

- 원칙 1: PIR이 지속적으로 False라면 다른 센서 패턴과 무관하게 낙상으로 확정하지 않는다.
- 원칙 2: ToF 거리가 400mm 이상이라면 FALL_CONFIRMED로 전이하지 않는다.
- 원칙 3: ABNORMAL_DETECTED 또는 FALL_ANALYZING 상태에서 반드시 TTS 음성 확인을 수행한다.
- 원칙 4: 사용자가 정상 응답하면 즉시 NORMAL로 처리하고 이벤트를 종료한다.
- 원칙 5: 모든 오탐 이벤트는 로그로 저장하여 추후 임계값 조정에 활용한다.

4. 오탐 vs 미탐 우선순위

오탐(정상을 낙상으로 판단)과 미탐(낙상을 정상으로 판단) 중 미탐이 더 위험하다.
따라서 판단이 불확실한 경우 오탐을 감수하더라도 FALL_ANALYZING 상태로 유지하고 TTS 확인 절차를 수행하는 것을 원칙으로 한다.
단, 과도한 오탐은 보호자 알림 피로감을 유발하므로 TTS 확인 절차를 통해 FALL_CONFIRMED 확정 전에 필터링한다.

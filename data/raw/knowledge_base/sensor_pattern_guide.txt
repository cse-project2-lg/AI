센서 패턴 가이드

1. 센서 개요

본 시스템은 WiFi CSI, PIR, ToF 세 가지 센서를 융합하여 낙상을 감지한다.
단일 센서만으로 판단하지 않고 세 센서의 복합 패턴을 분석하여 판단 정확도를 높인다.

2. 센서별 역할

2.1 WiFi CSI (Channel State Information)
- 역할: WiFi 신호의 채널 상태 변화를 통해 사용자의 움직임 패턴을 감지한다.
- 출력: amplitude 및 phase 변화량, 신호 분산값
- 특성: 사용자의 큰 움직임(낙상, 걷기 등)에서 변화량이 크게 증가한다.
- 한계: 물건 이동, 환경 변화에도 반응할 수 있어 단독 사용 시 오탐 가능성이 있다.

2.2 PIR (Passive Infrared Sensor)
- 역할: 적외선 감지를 통해 사용자의 재실 여부와 움직임 발생 여부를 감지한다.
- 출력: High(움직임 있음) 또는 Low(움직임 없음) 이진 신호
- 특성: 사람의 체온 변화를 감지하므로 물건 낙하에는 반응하지 않는다.
- 한계: 움직임의 크기나 방향은 구분하지 못한다.

2.3 ToF (Time of Flight)
- 역할: 레이저 펄스 반사 시간으로 사용자와 센서 간 거리를 측정하여 높이 변화를 감지한다.
- 출력: 밀리미터(mm) 단위 거리 측정값
- 특성: 낙상 시 발생하는 급격한 높이 하락 패턴을 정밀하게 감지한다.
- 한계: 센서 설치 위치에 따라 측정 범위가 달라질 수 있다.

3. 행동 상태 정의

시스템은 사용자 행동 상태를 다음 4가지로 관리한다.

- NORMAL: 사용자의 움직임이 정상 범위 내에 있으며 이상 징후가 없는 상태
- ABNORMAL_DETECTED: 센서 기반으로 일반적인 패턴과 다른 움직임이 감지된 상태 (낙상 가능성 존재)
- FALL_ANALYZING: 이상행동이 감지되어 LLM 분석 또는 추가 판단이 진행 중인 상태
- FALL_CONFIRMED: 분석 결과 실제 낙상으로 판단된 상태

4. 센서 패턴별 행동 상태 판단

4.1 FALL_CONFIRMED 판단 패턴

다음 패턴이 복합적으로 나타날 경우 FALL_CONFIRMED로 판단한다.

- PIR 상태: True (움직임 감지) 후 일정 시간(10초 이상) False (무동작) 지속
- ToF 거리: 300mm 이하로 급격히 감소 후 낮은 위치 유지
- CSI 변화량: 높음 (급격한 신호 변화)
- 사용자 응답: 없음
- 특징: 낙상 의심 정황(CSI 급변 + ToF 급락) 직후 PIR 무동작은 의식 불명 또는 신체 정지 상태를 나타내는 고위험 지표로 해석한다.

4.2 FALL_ANALYZING 판단 패턴

다음 패턴이 나타날 경우 LLM 분석을 통한 추가 판단이 필요한 FALL_ANALYZING 상태로 전이한다.

- PIR 상태: True 후 짧은 무반응(5~10초)
- ToF 거리: 300mm 이하로 감소
- CSI 변화량: 높음
- 사용자 응답: 확인 중 (TTS 확인 절차 수행)
- 특징: 낙상 여부가 불확실하여 LLM 및 RAG 기반 정밀 판단이 필요한 상태

4.3 ABNORMAL_DETECTED 판단 패턴

다음 패턴이 나타날 경우 이상 행동이 감지된 ABNORMAL_DETECTED 상태로 전이한다.

- PIR 상태: True (움직임 감지)
- ToF 거리: 300mm~400mm 구간 (불확실 구간)
- CSI 변화량: 중간 또는 높음
- 특징: 낙상 가능성이 있으나 추가 센서 데이터 확인이 필요한 상태. 복수 센서 동시 이상 여부를 확인한다.

4.4 NORMAL 판단 패턴

다음 패턴이 나타날 경우 정상 상태(NORMAL)로 판단한다.

앉기 또는 눕기:
- ToF 거리: 400mm 이상 유지 또는 점진적 감소 후 안정화
- PIR 상태: 움직임 감지 후 지속적인 소규모 움직임 유지
- CSI 변화량: 중간 수준
- 사용자 응답: 정상 응답 가능

물건 낙하 (오탐):
- PIR 상태: False (사람 움직임 없음)
- ToF 거리: 변화 없거나 미미함
- CSI 변화량: 낮거나 순간적 변화 후 즉시 안정화
- 특징: PIR False 상태에서는 CSI 변동과 ToF 급락이 있어도 사람의 낙상이 아닌 무생물 낙하로 판단한다.

환경 드리프트 (오탐):
- PIR 상태: False
- ToF 거리: 변화 없음
- CSI 변화량: 지속적이고 일정한 변화 (드리프트 패턴)
- 특징: 사람 움직임 없이 CSI만 지속 변화하는 경우 환경 변화로 인한 오탐으로 처리한다.

5. 센서 융합 판단 원칙

낙상 판단 시 다음 원칙을 따른다.

- 원칙 1: PIR 감지 여부를 최우선 판단 기준으로 사용한다. PIR이 지속적으로 False라면 낙상으로 확정하지 않는다.
- 원칙 2: ToF 거리 300mm 이하를 낙상 후보 기준으로 사용하고, 400mm 이상은 정상 활동으로 간주한다.
- 원칙 3: 단일 센서 이상만으로는 FALL_CONFIRMED로 확정하지 않는다. 복수 센서 조합을 통해 상태를 결정한다.
- 원칙 4: ABNORMAL_DETECTED 또는 FALL_ANALYZING 상태에서는 반드시 TTS 음성 확인 절차를 수행한다.
- 원칙 5: 판단이 불확실한 경우 FALL_ANALYZING 상태를 유지하며 LLM 분석을 수행한다.
- 원칙 6: LLM 판단 실패 시 rule-based 보수적 판단으로 폴백하여 FALL_CONFIRMED로 처리한다.

## 6. 시간대별 민감도 조정

- 주간(06시~22시): 일반 민감도 적용. 복수 센서 확인을 통해 오탐 방지.
- 야간(22시~06시): 높은 민감도 적용. ABNORMAL_DETECTED 발생 시 즉시 FALL_ANALYZING으로 전이 가능.
- 장시간 무동작(30분 이상): ABNORMAL_DETECTED 상태로 전이하고 TTS 음성 확인 권장.
